## Version and completeness

This is a historical source snapshot, not a copy of the active production plugin. The package header identifies version 3.3.13; the live WordPress plugin list reported BDS Marvel App 3.4.5. The compiled `build/static` bundles and media assets are not included here, so this directory is for source review and change tracking, not direct plugin installation.

Other active BDS Marvel custom plugins were also not available as downloadable source packages during this capture. Add their source when a current export is available. The site theme is intentionally deferred for a later repository pass.
